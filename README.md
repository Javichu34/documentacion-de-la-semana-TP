# documentacion-de-la-semana-TP
documentacion hecha en grupo sobre la semana TP (no la repitan)

El proyecto se trata de una app que lea archivos .PDF y pasarlo a un audio (Audiolibro)
con opciones unicas de cambiar las voces de las IAs para mayor inmercion.

toda la evidencia esta en la carpeta IMAGENES ademas de que nuestro proyecto no ocupamos nada externo como un arduino o cables 
todo fue hecho desde flutterflow asi que no podemos poner diagramas de circuito
